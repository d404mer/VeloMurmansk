Настройки события

На главную

Вы даёте судьям адрес ниже. Они отправляют JSON, приложение принимает его само. Опрос Limetime — запасной режим.

Приём данных

{{ ingestUrl }} {{ ingestCopyStatus }}

Content-Type: application/json · POST. ПК судей в той же сети; в Windows Firewall откройте TCP-порт.

Также: {{ ingestUrls.slice(1).join(', ') }}

Непустой JSON по категориям сохраняется в data/ingest/ и переживает перезапуск. Пустой POST файлы не затирает. Судьям в интернет — ngrok-URL (см. README), не LAN с панели.

Смена host/port применяется после перезапуска node server.js. Сейчас процесс слушает {{ listenHost }}:{{ listenPort }}.

Вставьте Limetime-ссылки для каждой категории. Формат: .../results/get/{raceGuid}/{stageGuid}/{categoryGuid}

Названия и ID категорий используются для панели и categoryId в POST. Limetime-ссылки необязательны.
