## 1. Что умеет система

Приложение подключается к **Limetime API** (тот же источник, что и racetime.online), забирает результаты велогонки и раздаёт их в несколько каналов:

| Возможность | Описание |
|-------------|----------|
| **Опрос Limetime** | Автоматически каждые 5 сек (настраивается) |
| **4 категории** | Женщины, мужчины, юниорки, юниоры — одно событие |
| **7 полей участника** | Место, участник, номер, возраст, клуб, результат, до лидера |
| **3 режима данных** | Стартовый лист → промежуточные (live) → финал |
| **vMix TCP** | Старт-листы, таблицы результатов, winners 1–3, тройной титр |
| **Плашки кругов** | Browser Source — титры под таймер при прохождении круга |
| **Excel** | Автообновление `exports/data.xlsx` по всем категориям |
| **Заморозка** | Фиксация снимка для эфира после финиша |

### Куда идут данные

```
Limetime API
     │
     ├──► Главная панель (браузер)
     ├──► vMix TCP — старт, результаты, winners
     ├──► Browser /laps — отсечки (круги)
     └──► Excel — архив по категориям
```

**Не через vMix TCP:** отсечки (только страница `/laps`), детальная история кругов (только Excel / внутренние данные).

## 2. Требования и установка

### Нужно

- **Node.js 18+**
- **Windows** (проверено на Windows 10/11)
- **vMix** — опционально, для оверлеев по TCP
- **Браузер** — для панели и Browser Source в vMix
- Файл **`exports/data.xlsx` не должен быть открыт в Excel** во время работы сервера

### Установка

```powershell
cd "D:\Для работы с судейкой\velo"
npm install
node server.js
```

В консоли должно появиться:

```
Limetime parser running on http://localhost:3000
```

Если vMix запущен и TCP API включён:

```
vMix Connected!
```

### Другой порт

```powershell
$env:PORT=8080; node server.js
```

### Если порт занят

```powershell
netstat -ano | findstr :3000
taskkill /PID <номер_из_последней_колонки> /F
node server.js
```

Не запускайте второй `node server.js`, пока первый не остановлен.

## 3. Первичная настройка

### Способ A — через веб-форму (рекомендуется)

1. Откройте **http://localhost:3000/config**
2. Укажите **название** и **ID** события (латиница, без пробелов)
3. Вставьте **4 ссылки Limetime** — по одной на категорию
4. Убедитесь, что под каждой ссылкой отображаются три GUID
5. Нажмите **«Сохранить»**

### Откуда взять ссылку

1. Откройте страницу результатов на racetime.online
2. Переключите нужную категорию
3. DevTools → **Network** → найдите запрос к `services-results.limetime.io`
4. Скопируйте полный URL

Формат:

```
https://services-results.limetime.io/results/get/{raceGuid}/{stageGuid}/{categoryGuid}
```

| GUID в URL | Назначение |
|------------|------------|
| 1-й (`raceGuid`) | Одно событие для всех 4 категорий — **должен совпадать** |
| 2-й (`stageGuid`) | Этап / старт категории |
| 3-й (`categoryGuid`) | Сама категория |

### Способ B — config.json вручную

Отредактируйте [`config.json`](config.json) и **перезапустите сервер**.

## 4. Главная панель

**URL:** http://localhost:3000

### Элементы управления

| Элемент | Действие |
|---------|----------|
| **Селектор категории** | Какая группа идёт в vMix, на панель и в плашки |
| **Обновить** | Принудительный запрос к Limetime |
| **Сохранить в Excel** | Записать `exports/data.xlsx` |
| **Настройки** | Страница `/config` |
| **Плашки кругов** | Открыть `/laps` для Browser Source |
| **Тест плашек** | `/laps?test=1` — панель проверки |
| **Заморозить данные** | Зафиксировать снимок для vMix и плашек |

### Индикаторы

- **Режим:** Стартовый лист / Промежуточные (live) / Финал — определяется автоматически из API
- **Данные заморожены** — vMix и плашки показывают снимок, Limetime в фоне всё ещё опрашивается
- **Live в API** — если заморожено, видно расхождение между эфиром и «живыми» данными

### Список участников

- Участники разбиты на **страницы по 10 человек**
- **Клик по странице** — отправляет эти 10 строк в vMix в шаблоны `result` и `startlist` (ручной вывод)

### Кнопки vMix внизу

| Кнопка | Что делает |
|--------|------------|
| **WINNER 1** | Заполняет персональный титр 1-го места и выводит overlay |
| **WINNER 2** | То же для 2-го места |
| **WINNER 3** | То же для 3-го места |
| **WINNERS** | Тройной титр — топ-3 в одном шаблоне |

Имена Inputs берутся из `config.json` → `vmix.templates`.

## 5. Плашки кругов (отсечки лидера)

**Назначение:** титры под таймером в эфире — **отсечка лидера** при прохождении им нового круга.

### Логика отсчёта

- Круг засчитывается, когда **лидер** (`position === 1`) завершает новый круг в Limetime.
- Плашка показывает **только лидера** (место, номер, ФИО, до лидера).
- После отсечки на круге N: `completedLap = N`, `currentLap = N + 1` («сейчас идёт круг N+1»).
- **Первый poll** после старта/смены категории — тихий (без плашек), запоминается текущий круг лидера.
- Текущий круг пишется в **vMix-титр** (`lapcounter`) и лист **«Эфир»** в `exports/data.xlsx`.

### Панель на главной

Блок **«Отсечки лидера»**: текущий/завершённый круг, лидер, время отсечки, кнопки **+1 круг (тест)** и **Сбросить счётчик**.

### Подключение в vMix

1. Добавьте **Browser Input**
2. URL: `http://localhost:3000/laps`
3. Разрешение: **1920×1080**
4. Включите **Transparent Background**
5. Нажмите **Refresh** после каждого обновления кода

### Поведение

- Одновременно на экране **до 4 плашек**
- Новая появляется **снизу**, верхняя уходит, остальные смещаются вверх
- Плашка: **место | номер | ФИО | до лидера**
- ФИО: **ИМЯ ФАМИЛИЯ**, UPPERCASE
- Появляются **только при новом круге лидера** (не для каждого участника)

### Режимы тестирования

| URL / действие | Назначение |
|----------------|------------|
| Главная → **+1 круг (тест)** | Симуляция отсечки лидера + vMix/Excel |
| `/laps?demo=1` | Бесконечная карусель без API — проверка вёрстки |
| `/laps?test=1` | Панель: случайная плашка, +1 круг лидера, Replay лидера, Очистить |
| `/laps?categoryId=men` | Фиксировать категорию (не следовать за главной) |

### Настройка позиции и размера

**URL-параметры** (удобно в vMix без правки файлов):

```
http://localhost:3000/laps?left=230&width=424&top=154
```

| Параметр | Описание |
|----------|----------|
| `left` | Отступ слева (px) |
| `top` | Отступ сверху (px) |
| `width` | Общая ширина плашки (блок имени растягивается) |
| `place`, `number`, `gap` | Ширина отдельных блоков |
| `innerGap` | Зазор между блоками внутри плашки (7 px) |
| `stackGap` | Зазор между плашками (7 px) |

**Или** правьте переменные в [`public/css/laps.css`](public/css/laps.css) в блоке `:root`.

После изменений — **Refresh** в Browser Input vMix.

### Заморозка и плашки

При **«Заморозить данные»** новые плашки **не появляются**. Уже показанные остаются на экране.

## 6. vMix: шаблоны и поля

### Автообновление

При `vmix.autoUpdate: true` сервер каждые ~5 сек заполняет шаблоны для **активной категории** с главной панели.

### Таблица шаблонов

| Тип | Inputs по умолчанию | Источник данных |
|-----|---------------------|-----------------|
| Стартовый лист | `startlist1` … `startlist5` | Всегда `startList` |
| Результаты (live) | `res1` … `res5` | `liveList`, пока гонка идёт |
| Результаты (финал) | `res1` … `res5` | `finalList`, когда все финишировали |
| 1-е место | `winner1` | Топ-1 |
| 2-е место | `winner2` | Топ-2 |
| 3-е место | `winner3` | Топ-3 |
| Тройной титр | `winners` | Строки 1–3 |
| Текущий круг | `lapcounter` | `currentLap`, лидер, время отсечки |

### Титр текущего круга (`lapcounter`)

В `config.json` → `vmix.lapCounter`:

```json
"lapCounter": {
  "template": "lapcounter",
  "fields": {
    "lap": "lap.Text",
    "leader": "leader.Text",
    "time": "time.Text"
  }
}
```

Обновляется при каждой новой отсечке лидера активной категории.

На каждой **странице** таблицы — **10 строк** (`pageSize: 10`, до 5 страниц = 50 участников).

### Текстовые поля в GT

По умолчанию (для строки `N`):

| Поле | Имя в vMix |
|------|------------|
| Место | `place N.Text` |
| Номер | `num N.Text` |
| Участник | `name N.Text` |
| Клуб | `club N.Text` / `city N.Text` |
| Возраст | `age N.Text` |
| Результат | `result N.Text` |
| До лидера | `gap N.Text` |

Персональные winners используют **строку 1** (`place 1.Text`, `name 1.Text`, …).

Все имена настраиваются в `config.json` → `vmix.fields`.

### Настройка имён Inputs

В [`config.json`](config.json):

```json
"vmix": {
  "templates": {
    "resultsPage": "res{page}",
    "startlistPage": "startlist{page}",
    "winner1": "winner1",
    "winner2": "winner2",
    "winner3": "winner3",
    "winners": "winners",
    "resultManual": "result",
    "startlistManual": "startlist"
  }
}
```

`{page}` заменяется на 1, 2, 3…

### Старые имена (lider / liders4)

Если в проекте vMix ещё старые Inputs:

```json
"legacy": {
  "winner1": "lider",
  "winners": "liders4"
}
```

### Подготовка vMix

1. vMix запущен на том же ПК, что и сервер
2. **Settings → Web Controller → TCP API** — включён
3. Имена Inputs в vMix **точно совпадают** с `vmix.templates`
4. В GT-шаблонах есть текстовые поля с именами из `vmix.fields`

## 7. Заморозка данных после финиша

### Зачем

После финиша Limetime может **пересчитывать места**, менять ФИО, «скакать» данные. Для эфира нужен **стабильный снимок**, чтобы успеть поправить титры вручную.

### Как пользоваться

1. Гонка закончилась, финальные места на экране
2. Нажмите **«Заморозить данные»** на главной
3. vMix продолжает показывать **зафиксированный** снимок
4. Новые **плашки кругов** не появляются
5. **Excel** и опрос Limetime в фоне **продолжают работать**
6. Когда готовы — **«Снять заморозку»**

### Что заморожено / что нет

| Компонент | При заморозке |
|-----------|---------------|
| vMix auto-update | Снимок на момент freeze |
| Плашки `/laps` | Новые не приходят |
| Главная панель | Показывает замороженный список |
| Excel | Обновляется как обычно |
| Опрос Limetime | Продолжается |

### API (для автоматизации)

```http
POST /api/freeze
Content-Type: application/json

{ "frozen": true }
```

Снять заморозку: `{ "frozen": false }`.

## 8. Excel

### Файл

`exports/data.xlsx` — один файл, **отдельный лист на каждую категорию** (имя листа = название категории из config).

### Колонки

| Место | Участник | Номер | Возраст | Клуб | Результат | До лидера |

### Обновление

- **Автоматически** каждые 5 сек при poll (если файл **не открыт** в Excel)
- **Вручную** — кнопка «Сохранить в Excel» на главной

### Ошибка EBUSY

Если в консоли `data.xlsx занят` — **закройте файл в Excel**. Сервер продолжит работать, экспорт возобновится на следующем цикле.

## 9. Сценарий работы в эфире

### До старта

1. `node server.js` — сервер запущен
2. vMix: Browser Source `/laps` добавлен, Refresh сделан
3. В `/config` проверены все 4 категории
4. На главной выбрана **нужная категория**
5. В vMix видны стартовые листы (`startlist*`)

### Во время гонки

1. Таблицы `res*` обновляются (live)
2. Плашки на `/laps` появляются при каждом новом круге
3. При необходимости — **WINNER 1/2/3** или **WINNERS** для титров
4. Клик по странице списка — ручной вывод 10 строк

### После финиша

1. Режим переключается на **Финал**, `res*` = итоговая таблица
2. **Заморозить данные** — если Limetime начинает «скакать»
3. Поправить титры в vMix вручную при необходимости
4. Excel сохранён для архива

### Смена категории

На главной выберите другую категорию в dropdown — сервер переключит vMix, панель и плашки (если не задан `categoryId` в URL `/laps`).

## 10. Конфигурация config.json

### Основные поля

```json
{
  "limetime": {
    "baseUrl": "https://services-results.limetime.io/results/get",
    "apiKey": "...",
    "origin": "https://racetime.online",
    "referer": "https://racetime.online/"
  },
  "pollIntervalMs": 5000,
  "activeEventId": "xcochamp2025",
  "activeCategoryId": "men",
  "events": [ ... ],
  "vmix": { ... }
}
```

| Поле | Описание |
|------|----------|
| `limetime.apiKey` | Ключ из DevTools (заголовок `limetime-api-key`) |
| `pollIntervalMs` | Интервал опроса, мс (5000 = 5 сек) |
| `activeCategoryId` | Категория по умолчанию при старте |
| `vmix.host` | Обычно `localhost` |
| `vmix.autoUpdate` | `true` — слать в vMix при каждом poll |
| `vmix.pageSize` | Строк на страницу (10) |
| `vmix.maxPages` | Макс. страниц (5 → 50 участников) |

После правки `config.json` — **перезапуск сервера** (кроме сохранения через `/config`, там перезапуск не нужен).

## 11. Частые проблемы

### vMix не обновляется

- vMix запущен, TCP API включён
- В консоли есть `vMix Connected!`
- `vmix.autoUpdate: true`
- Имена Inputs совпадают с config
- Не включена заморозка (или это ожидаемо)

### Плашки в vMix не как в браузере

- Browser Input: **1920×1080**, **Transparent Background**
- Нажмите **Refresh** у Browser Input
- Добавьте `?v=` или измените URL, чтобы сбросить кэш
- vMix использует **отдельный** Chromium — проверяйте сначала в Chrome

### Плашки не появляются в эфире

- URL без `?demo=1`
- Гонка **live** — в архиве новых кругов нет
- Не включена заморозка
- Сервер только что запущен — первый poll не создаёт плашек (только запоминает круги)

### Failed to load категория

- Неверный GUID в config
- Гонка ещё не началась на Limetime
- Проверьте ссылку в `/config`

### Limetime API unsuccessful

- API-ключ устарел
- URL обрезан или от другого события
- `raceGuid` не совпадает между категориями
